# V9 Approved Design

This build implements the approved homepage/dashboard direction rather than continuing to patch the older layout.

Key decisions:
- "One Workspace. Eight Libraries." with capital W and L.
- No branch logos beside branch names on the homepage.
- Real branch exterior imagery is preserved.
- Coastal hero uses the supplied Lahaina coastal image.
- HSPLS affiliation is prominent but secondary.
- Public-prototype / future authentication messaging is immediately visible.
- Atlas supports formatted Markdown and remains embedded in the site.
- Edit Mode is visibly functional with a local toolbar, add workflows, local persistence, remove/reset controls, and editable branch labels.
- Public edits remain browser-local by design; production editing requires authenticated, role-based access.
